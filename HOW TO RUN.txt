Restock bot (One Piece + Pokémon) - how to run it

Start it, or restart it after an update:   double-click restart_bot.bat
Make it start by itself at every login:    double-click install_autostart.bat (once; it also starts it now)
Stop it starting by itself:                remove_autostart.bat

Within a minute or two, Discord's #bot-status shows "Bot online (PC, v2.11.0)".
Pokémon channels: type /pokemon setup in Discord (once).
One Piece in-store channel: type /onepiece setup in Discord (once).

If something looks wrong, open bot_output.log in this folder and send Claude the last few lines.

New in v2.5: /watch add <link> <max> watches any product page; /ebay list|check|max|add|remove; /bought <card>.
New in v2.7: /value <card> shows what a single's worth at the shops now, with a price chart for the last week.
  For the chart picture, once:  py -3 -m pip install matplotlib   (without it /value shows a text sparkline).
  The week fills out over the first 7 days after updating (the bot used to keep only 2 days of single prices).

New in v2.8: TCGplayer prices (tcgplayer.py, via TCGCSV - TCGplayer's own data, refreshed daily, no key needed).
  The cloud copy downloads them every morning (~7:45am) and posts a daily report: biggest movers, singles
  cheaper at Elemental Arcade / Good Games than TCGplayer's market, booster box prices, and your want list.
  /tcgp <search> looks up any card or sealed product, e.g. /tcgp OP13-120 or /tcgp op13 booster box.
  /value now shows TCGplayer's market (in A$) under each version too.
New in v2.9: /pricecheck deck <deck> says what a whole deck costs to buy right now.
  Pick a saved deck or a want-list deck (your "deck" tags) from the list, or paste a decklist
  (1xOP12-001 4xOP12-016 ...). It shows the cheapest play copy in stock at Elemental Arcade / Good Games,
  what's not in stock, and the TCGplayer total. Collector versions (Wanted Poster, alt art...) don't count.
  /pricecheck save name:<name> list:<decklist> keeps a deck (or attach the .txt export) · /pricecheck list
  Saved decks live in decks.json; the updater never touches it.

  Its own channel (optional): double-click add_channels.bat, then add DISCORD_WEBHOOK_PRICES to GitHub
  as it says. Until then the report posts in the price-drops channel.
New in v2.10: One Piece in-store section (#onepiece-in-store), the One Piece twin of #pokemon-in-store.
  The evening before a release (6pm) it posts "tomorrow in stores"; at 7am on the day "out today" (pings the
  One Piece ping role), with what's out, which online shops have it right now and where to look on a shelf.
  /onepiece report  - spotted stock in a store? posts it there for everyone (store, what, price, photo).
  /onepiece instore - sightings from the last 24 hours.   /onepiece releases - the calendar + drop windows.
  Set it up once: /onepiece setup in Discord (admins), then add the DISCORD_WEBHOOK_INSTORE secret it shows
  to GitHub so the cloud copy can post when the PC is off. Until then the section is quiet (nothing else changes).
  Options in config.json, all optional:  "instore": {"evening": "18:00", "morning": "07:00", "ping": true,
  "online": true, "stores": ["EB Games / Zing", "Big W", "Kmart", "Target", "JB Hi-Fi", "your local game store"]}
New in v2.11: AUTO-BUY. The PC checks out restocks by itself (booster boxes and /watch links, Shopify shops,
  no pre-orders), within limits you set. It never types or stores your card: it uses its own Chrome profile that
  you sign in to Shop Pay with, once.
  Set it up once:  double-click setup_autobuy.bat. It installs what it needs and opens a Chrome window.
                   Sign in to Shop Pay (shop.app) with your address and card saved, sign in to any shops you
                   have accounts with, then close the window.
  Then in Discord: /autobuy try link:<a product page at a shop you buy from>  - a test run, never pays,
                   posts a screenshot of the checkout in #bot-status. Try each shop you care about.
                   /autobuy set mode:test  - real restocks go all the way to the Pay button, but no further
                   /autobuy set mode:live per_order:300 per_day:300  - really buys
                   /autobuy set mode:off   /autobuy status
  It stops and posts the checkout link for you whenever a shop wants a sign-in, captcha, card or address, or
  the total (with postage) is over your limits. If your bank asks to approve the payment, you get a phone push.
  Limits and options: "auto_buy" in config.json (see the top of auto_buy.py).
